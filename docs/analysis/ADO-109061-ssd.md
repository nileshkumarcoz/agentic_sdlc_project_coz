## 2. Component Breakdown

### 2.1 Frontend Upload UI
- React component `RequirementUploader` added to the existing frontend package.
- Supports drag-and-drop for PDF, DOCX, TXT, MD files (max 20 MB).
- Displays generated stories in a review table with inline edit capability.
- Allows PO to accept / reject / edit individual stories before saving to backlog.

### 2.2 API Gateway — New Endpoints
| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/stories/generate` | Trigger story generation from uploaded document |
| GET | `/api/v1/stories/jobs/{job_id}` | Poll async job status |
| GET | `/api/v1/stories/{story_id}` | Retrieve a single generated story |
| PUT | `/api/v1/stories/{story_id}` | PO edits/approves a story |
| POST | `/api/v1/stories/{story_id}/export` | Export stories to Jira/Azure DevOps |

Implemented in `app/api/routes/story_generator.py` following existing FastAPI router conventions in the repo.

### 2.3 StoryGeneratorAgent (LangChain Agent)
File: `app/agents/story_generator_agent.py`

1. **DocumentParserTool** — Extracts raw text; uses `pdfplumber` for PDF, `python-docx` for DOCX, native read for TXT/MD.
2. **RequirementExtractTool** — LLM prompt chain that identifies and labels Business Requirements (BR-*) and Functional Requirements (FR-*) with source page/section references.
