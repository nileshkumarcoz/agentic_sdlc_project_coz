# Solution Design Document
## Story ID: 109412 — Add Two Numbers Using Python

---

### 1. Proposed Architecture & Components

The solution follows a **layered CLI architecture** with clear separation between I/O, validation, business logic, and testing.

```
agentic_sdlc_project_coz/
├── add_two_numbers/
│   ├── __init__.py          # Makes module importable
│   ├── calculator.py        # Core logic: validate_input(), calculate_sum()
│   └── main.py              # CLI entry point: get_user_input(), display_result()
├── tests/
│   ├── __init__.py
│   └── test_calculator.py   # Unit & integration tests
├── requirements-dev.txt     # pytest only (no runtime dependencies)
└── README.md                # Usage instructions
```

**Component Responsibilities:**

| Component | Responsibility |
|---|---|
| `calculator.py` | Pure functions: input validation and addition. Zero I/O side-effects. |
| `main.py` | Orchestrates user prompts, calls calculator functions, prints results/errors. |
| `test_calculator.py` | Validates all functional and edge-case scenarios using `pytest`. |

---

### 2. Data Model

No persistent data model is required. The in-memory data flow is:

```
raw_input_1: str  ──► validated_num_1: float
raw_input_2: str  ──► validated_num_2: float
                                        │
                              calculate_sum() → result: float
                                        │
                              display_result() → stdout string
```

**Type Definitions (logical):**
```python
raw_input   : str          # Direct output of input() call
validated   : float        # Post-validation numeric value
result      : float        # Sum of two validated floats
error_msg   : str | None   # None if valid, descriptive string if invalid
```

### 3. Key APIs / Interfaces

#### 3.1 `calculator.py`

```python
def validate_input(value: str) -> float:
    """
    Validates that the input string is a non-empty numeric value.

    Args:
        value (str): Raw string input from the user.

    Returns:
        float: The numeric representation of the input.

    Raises:
        ValueError: If the input is empty or cannot be converted to float.
    """
    if not value.strip():
        raise ValueError("Input must not be empty.")
    return float(value.strip())


def calculate_sum(a: float, b: float) -> float:
    """
    Computes and returns the sum of two numeric values.

    Args:
        a (float): First number.
        b (float): Second number.

    Returns:
        float: The arithmetic sum a + b.
    """
    return a + b
```

### 5. Concrete Implementation

#### `add_two_numbers/calculator.py`
```python
def validate_input(value: str) -> float:
    if not value.strip():
        raise ValueError("Input must not be empty.")
    try:
        return float(value.strip())
    except ValueError:
        raise ValueError(f"'{value.strip()}' is not a valid numeric value.")


def calculate_sum(a: float, b: float) -> float:
    return a + b
```

#### `add_two_numbers/main.py`
```python
from add_two_numbers.calculator import validate_input, calculate_sum


def main() -> None:
    print("=== Add Two Numbers ===")
    try:
        raw1 = input("Enter the first number: ")
        num1 = validate_input(raw1)

        raw2 = input("Enter the second number: ")
        num2 = validate_input(raw2)

        result = calculate_sum(num1, num2)
        print(f"Result: {num1} + {num2} = {result}")

    except ValueError as e:
        print(f"Error: {e}")


if __name__ == "__main__":
    main()
```

### 6. Technology Choices

| Concern | Choice | Rationale |
|---|---|---|
| Language | Python 3.8+ | Specified in story; zero-dependency runtime |
| Type conversion | Built-in `float()` | Handles both int and float strings natively |
| Error handling | `try/except ValueError` | Standard Pythonic pattern; prevents crashes |
| Testing framework | `pytest` | Industry standard; minimal setup; rich assertion introspection |
| Code style | PEP 8 + `flake8` (dev) | Enforces maintainability NFR |
| CI (optional) | GitHub Actions / repo pipeline | Runs `pytest` on push; enforces Definition of Done |

---

### 7. Non-Functional Design

#### 7.1 Security
- No external input is evaluated (no `eval()` usage) — prevents code injection.
- All inputs sanitised through `float()` conversion inside `try/except`.

#### 7.2 Scalability
- Not applicable for a CLI utility; the function is O(1) and stateless, making it trivially extensible to a REST endpoint or batch processor if needed.

#### 7.3 Observability
- Error messages are printed to `stdout` for CLI visibility.
- Future enhancement: use Python `logging` module with `DEBUG`/`ERROR` levels for integration into larger systems.

#### 7.4 Maintainability
- Pure function `calculate_sum` is side-effect free and independently testable.
- `main()` is separated from `if __name__ == "__main__"` guard to allow import-time testing.

### 8. Test Strategy

#### `tests/test_calculator.py`

| Test ID | Scenario | Input | Expected Output |
|---|---|---|---|
| TC-01 | Happy path: two integers | `"3"`, `"7"` | `10.0` |
| TC-02 | Happy path: two floats | `"1.5"`, `"2.5"` | `4.0` |
| TC-03 | Happy path: negative numbers | `"-5"`, `"3"` | `-2.0` |
| TC-04 | Happy path: zero values | `"0"`, `"0"` | `0.0` |
| TC-05 | Invalid: non-numeric string | `"abc"`, `"2"` | `ValueError` raised |
| TC-06 | Invalid: empty string | `""`, `"2"` | `ValueError` raised |
| TC-07 | Invalid: whitespace only | `" "`, `"2"` | `ValueError` raised |
| TC-08 | Invalid: special character | `"@"`, `"1"` | `ValueError` raised |
| TC-09 | Large numbers | `"1e15"`, `"1e15"` | `2e15` |
| TC-10 | Mixed int and float | `"10"`, `"0.5"` | `10.5` |

```python
import pytest
from add_two_numbers.calculator import validate_input, calculate_sum


class TestValidateInput:
    def test_valid_integer(self):
        assert validate_input("42") == 42.0

    def test_valid_float(self):
        assert validate_input("3.14") == 3.14

    def test_empty_string_raises(self):
        with pytest.raises(ValueError, match="must not be empty"):
            validate_input("")

    def test_whitespace_only_raises(self):
        with pytest.raises(ValueError, match="must not be empty"):
            validate_input("   ")

    def test_non_numeric_raises(self):
        with pytest.raises(ValueError, match="not a valid numeric value"):
            validate_input("abc")


class TestCalculateSum:
    def test_positive_integers(self):
        assert calculate_sum(3.0, 7.0) == 10.0

    def test_negative_numbers(self):
        assert calculate_sum(-5.0, 3.0) == -2.0

    def test_zeros(self):
        assert calculate_sum(0.0, 0.0) == 0.0

    def test_large_numbers(self):
        assert calculate_sum(1e15, 1e15) == 2e15

    def test_mixed_types(self):
        assert calculate_sum(10.0, 0.5) == 10.5
```
