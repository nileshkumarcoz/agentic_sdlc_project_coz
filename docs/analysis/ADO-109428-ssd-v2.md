# Solution Design Document — REVISED
## Story ID: 109428 — Find the Largest **and Smallest** Number

> **Revision Summary (per Nilesh Kumar feedback):** The previous SSD returned only the largest number. This version adds `find_smallest()` (and `find_min_max()` convenience function), updates all APIs, payloads, sequence diagrams, CLI output, and test cases to also surface the **smallest number**. The middle/median value is included as an optional informational field.

### 6. Core Logic Implementation *(REVISED — adds find_smallest and find_min_max_middle)*

```python
# src/core/number_analysis.py
import math
from dataclasses import dataclass
from typing import Optional


@dataclass
class ValidationResult:
    is_valid: bool
    parsed_values: Optional[list[float]] = None
    error_message: Optional[str] = None
    error_field: Optional[str] = None


@dataclass
class NumberAnalysisResult:
    largest: float
    smallest: float
    middle: float
    inputs: list[float]


MAX_INPUT_LENGTH = 50


def validate_input(raw_inputs: dict[str, str]) -> ValidationResult:
    parsed: list[float] = []
    for field in ["number1", "number2", "number3"]:
        value = raw_inputs.get(field, "").strip()
        if not value:
            return ValidationResult(
                is_valid=False,
                error_message=f"Field '{field}' cannot be empty.",
                error_field=field,
            )
        if len(value) > MAX_INPUT_LENGTH:
            return ValidationResult(
                is_valid=False,
                error_message=f"Field '{field}' exceeds maximum length of {MAX_INPUT_LENGTH}.",
                error_field=field,
            )
        try:
            number = float(value)
        except ValueError:
            return ValidationResult(
                is_valid=False,
                error_message=f"Invalid input: '{value}' is not a valid number.",
                error_field=field,
            )
        if math.isnan(number) or math.isinf(number):
            return ValidationResult(
                is_valid=False,
                error_message=f"Invalid input: '{value}' is not a finite number.",
                error_field=field,
            )
        parsed.append(number)
    return ValidationResult(is_valid=True, parsed_values=parsed)


def find_largest(numbers: list[float]) -> float:
    """Returns the maximum of exactly 3 floats."""
    if len(numbers) != 3:
        raise ValueError("Exactly 3 numbers are required.")
    return max(numbers)


def find_smallest(numbers: list[float]) -> float:
    """Returns the minimum of exactly 3 floats."""
    if len(numbers) != 3:
        raise ValueError("Exactly 3 numbers are required.")
    return min(numbers)


def find_min_max_middle(numbers: list[float]) -> NumberAnalysisResult:
    """
    Returns largest, smallest, and middle value from exactly 3 floats.
    The middle value is the median (the value that is neither max nor min).
    """
    if len(numbers) != 3:
        raise ValueError("Exactly 3 numbers are required.")
    sorted_nums = sorted(numbers)
    return NumberAnalysisResult(
        largest=sorted_nums[2],
        smallest=sorted_nums[0],
        middle=sorted_nums[1],
        inputs=numbers,
    )
```

### 7. Handler Implementation *(REVISED)*

```python
# src/handlers/number_analysis_handler.py
import logging
from src.core.number_analysis import validate_input, find_min_max_middle, NumberAnalysisResult
from src.core.number_analysis import ValidationResult

logger = logging.getLogger(__name__)


def handle_number_analysis(raw_inputs: dict[str, str]) -> dict:
    logger.debug("number_analysis request received: inputs=%s", raw_inputs)

    validation: ValidationResult = validate_input(raw_inputs)
    if not validation.is_valid:
        logger.warning(
            "Validation failed: field=%s, reason=%s",
            validation.error_field,
            validation.error_message,
        )
        return {
            "status": "error",
            "message": validation.error_message,
            "field": validation.error_field,
        }

    result: NumberAnalysisResult = find_min_max_middle(validation.parsed_values)
    logger.info(
        "number_analysis result: largest=%s, smallest=%s, middle=%s",
        result.largest, result.smallest, result.middle,
    )
    return {
        "status": "success",
        "largest": result.largest,
        "smallest": result.smallest,
        "middle": result.middle,
        "inputs": result.inputs,
    }
```

### 8. Non-Functional Design

#### 8.1 Security
- All inputs treated as untrusted strings; parsed only via `float()` — no `eval()` or `exec()`
- `math.isnan()` and `math.isinf()` guards reject special float values
- Input length capped at 50 characters to prevent DoS via enormous strings
- REST endpoint validates `Content-Type: application/json` header

#### 8.2 Scalability
- Fully stateless, O(1) computation — scales horizontally with no additional infrastructure concern
- No database reads/writes; no shared mutable state between requests

#### 8.3 Observability
- DEBUG log: raw inputs received per request
- WARNING log: validation failure with field name and raw value
- INFO log: successful result with largest, smallest, and middle values
- Uses Python `logging` module, consistent with project-wide logger configuration
