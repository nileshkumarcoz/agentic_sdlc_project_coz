## 4. Key APIs / Interfaces

### 4.1 Auth Endpoints (PUBLIC — No JWT Required)
| Method | Path | Lambda | Description |
|---|---|---|---|
| POST | `/auth/register` | `auth_handler` | Create new Cognito user account |
| POST | `/auth/login` | `auth_handler` | Authenticate user; return JWT tokens |
| POST | `/auth/logout` | `auth_handler` | Invalidate refresh token via Cognito |
| POST | `/auth/refresh` | `auth_handler` | Exchange refresh token for new access token |

### 4.2 Protected Business Endpoints (JWT Required)
| Method | Path | Lambda | Description |
|---|---|---|---|
| POST | `/v1/process` | `api_handler` | Trigger synchronous processing |
| GET | `/v1/status/{id}` | `api_handler` | Retrieve processing status |
| GET | `/v1/health` | `api_handler` | Health check (public) |

### 4.3 `auth_handler` Lambda Interface
```python
# lambdas/auth_handler/handler.py
from aws_lambda_powertools import Logger, Tracer
from shared.utils.auth import route_auth_request

logger = Logger()
tracer = Tracer()

@logger.inject_lambda_context(log_event=False) # NEVER log raw event (contains passwords)
@tracer.capture_lambda_handler
def lambda_handler(event: dict, context) -> dict:
 """
 Routes /auth/* paths to register, login, logout, refresh handlers.
 Returns API Gateway Proxy response dict.
 """
 path = event.get("rawPath", "")
 method = event.get("requestContext", {}).get("http", {}).get("method", "")
 return route_auth_request(path, method, event)
```

```python
# lambdas/auth_handler/cognito_client.py
import boto3
from botocore.exceptions import ClientError

class CognitoAuthClient:
 def __init__(self, user_pool_id: str, client_id: str):
 self._client = boto3.client("cognito-idp")
 self.user_pool_id = user_pool_id
 self.client_id = client_id

 def register(self, email: str, password: str) -> dict:
 """Calls sign_up; returns Cognito UserSub."""

 def login(self, email: str, password: str) -> dict:
 """Calls initiate_auth (USER_PASSWORD_AUTH); returns AuthenticationResult."""

 def logout(self, access_token: str) -> None:
 """Calls global_sign_out to revoke all tokens for the user."""

 def refresh(self, refresh_token: str) -> dict:
 """Calls initiate_auth (REFRESH_TOKEN_AUTH); returns new AuthenticationResult."""
```

### 4.4 Shared Auth Utility
```python
# shared/utils/auth.py
import jwt # python-jose or PyJWT

def decode_and_verify_jwt(token: str, region: str, user_pool_id: str) -> dict:
 """
 Downloads Cognito JWKS, verifies signature, expiry, aud.
 Returns decoded claims dict.
 Raises jwt.InvalidTokenError on failure.

def get_user_sub_from_event(event: dict) -> str:
 """Extracts sub claim from API Gateway JWT authorizer context."""
```

## 5. Sequence Diagrams

### 5.1 User Registration Flow (NEW)
```
Client
 │
 │ POST /auth/register {email, password}
 ▼
API Gateway (no authorizer)
 │
 ▼
Lambda: auth_handler
 │── Validate payload (Pydantic)
 │── CognitoAuthClient.register(email, password)
 │ └─▶ Cognito User Pool: SignUp
 │ └─▶ Sends verification email
 │── Write audit record to DynamoDB (REGISTER event)
 │── Return 201 {message: "Verification email sent"}
 ▼
Client
```

### 5.2 User Login Flow (NEW)
```
Client
 │
 │ POST /auth/login {email, password}
 ▼
API Gateway (no authorizer)
 │
 ▼
Lambda: auth_handler
 │── Validate payload
 │── CognitoAuthClient.login(email, password)
 │ └─▶ Cognito: InitiateAuth (USER_PASSWORD_AUTH)
 │ ├─▶ Success: AuthenticationResult {AccessToken, RefreshToken, IdToken}
 │ └─▶ Failure: NotAuthorizedException → 401
 │── Write audit record to DynamoDB (LOGIN event, IP, UserAgent)
 │── Return 200 {access_token, refresh_token, token_type, expires_in}
 ▼
Client stores tokens (memory / secure cookie)
```

### 5.3 Protected API Call Flow (NEW)
```
Client
 │
 │ POST /v1/process
 │ Authorization: Bearer <access_token>
 ▼
API Gateway HTTP API
 │
 │── Cognito JWT Authorizer:
 │ │ Verify token signature against Cognito JWKS
 │ │ Check expiry, issuer, audience
 │ ├─▶ VALID → pass event + claims context to Lambda
 │ └─▶ INVALID → 401 Unauthorized (Lambda never invoked)
 ▼
Lambda: api_handler
 │── Extract user sub from event.requestContext.authorizer.jwt.claims
 │── Execute business logic
 │── Read/write DynamoDB
 │── Return 200 response
 ▼
Client
```

### 5.4 Token Refresh Flow (NEW)
```
Client
 │
 │ POST /auth/refresh {refresh_token}
 ▼
Lambda: auth_handler
 │── CognitoAuthClient.refresh(refresh_token)
 │ └─▶ Cognito: InitiateAuth (REFRESH_TOKEN_AUTH)
 │ ├─▶ Success: new AccessToken
 │ └─▶ Failure: NotAuthorizedException → 401
 │── Write audit record (REFRESH event)
 │── Return 200 {access_token, token_type, expires_in}
 ▼
Client replaces stored access_token
```

### 5.5 Logout Flow (NEW)
```
Client
 │
 │ POST /auth/logout
 │ Authorization: Bearer <access_token>
 ▼
Lambda: auth_handler
 │── CognitoAuthClient.logout(access_token)
 │ └─▶ Cognito: GlobalSignOut (revokes all tokens for user)
 │── Write audit record (LOGOUT event)
 │── Return 200 {message: "Logged out successfully"}
 ▼
Client clears stored tokens
```

### 5.6 Async SQS Flow (Unchanged)
```
Producer → SQS → Lambda (event_processor) [batch 1–10]
 Success → Delete messages
 Partial failure → SQS retry → DLQ after maxReceiveCount=3
 DLQ > 0 → CloudWatch Alarm → SNS
```

### 5.7 Scheduled Job Flow (Unchanged)
```
EventBridge (cron) → Lambda (scheduler) → SSM config → CloudWatch custom metric
```

## 7. Technology Choices

| Concern | Choice | Rationale |
|---|---|---|
| Identity / Auth | **Amazon Cognito User Pools** | Managed JWT issuance, password hashing, account lockout, token rotation — no custom auth server needed |
| API Authorization | **Cognito JWT Authorizer** (HTTP API native) | Zero-code token validation; Lambda never called on invalid token |
| Auth Lambda | `auth_handler` (Python 3.11) | Thin wrapper over Cognito SDK; handles register/login/logout/refresh |
| Token Format | **JWT (RS256)** issued by Cognito | Industry standard; verifiable without Cognito round-trip |
| Brute-force Protection | **AWS WAF** + Cognito built-in lockout | WAF rate-limit rule on `/auth/login`; Cognito locks after N failures |
| Runtime | Python 3.11 | Fast cold starts, Powertools support |
| IaC | AWS SAM | Native Lambda + Cognito + API Gateway support |
| Observability | AWS Lambda Powertools | Structured logging (tokens masked), X-Ray tracing |
| Secrets | AWS Secrets Manager | Cognito client secret (if used), DB creds |
| Async events | Amazon SQS + DLQ | ReportBatchItemFailures support |
| Scheduling | Amazon EventBridge | Serverless cron |
| CI/CD | GitHub Actions | SAM build + deploy |
| Testing | pytest + moto + pytest-mock | Unit + integration test coverage |

## 8. Security Design (Expanded)

### 8.1 Authentication Security Controls
| Control | Implementation |
|---|---|
| Password hashing | Delegated to Cognito (bcrypt/SRP internally) |
| Token expiry | Access token: 1 hour; Refresh token: 30 days |
| Token revocation | `GlobalSignOut` invalidates all tokens on logout |
| Brute-force lockout | Cognito Advanced Security (optional) + WAF rate limit rule: 10 req/min per IP on `/auth/login` |
| No token logging | `log_event=False` on auth Lambda; logger masks Authorization header |
| HTTPS only | API Gateway enforces TLS 1.2+ |
| CORS | API Gateway CORS configured to allowed origins only |

### 8.2 IAM Least Privilege
- `AuthHandlerRole`: Only `cognito-idp:SignUp`, `cognito-idp:InitiateAuth`, `cognito-idp:GlobalSignOut`, `dynamodb:PutItem` on AuditTable.
- `ApiHandlerRole`: Only `dynamodb:GetItem`, `dynamodb:PutItem` on business table. No Cognito permissions.
- `EventProcessorRole`: Only SQS `ReceiveMessage`/`DeleteMessage`, target service writes.
- `SchedulerRole`: Only SSM `GetParameter`, CloudWatch `PutMetricData`.

### 8.3 Secrets
- Cognito User Pool ID and Client ID stored in SSM Parameter Store (not Secrets Manager — not secret values).
- Any third-party API keys stored in Secrets Manager, fetched at cold start with 5-min cache.

## 9. Non-Functional Design

### 9.1 Scalability
- Cognito scales to millions of users managed.
- Auth Lambda: Reserved concurrency 100 to prevent auth traffic starving business Lambdas.
- Provisioned concurrency on `api_handler` (2 instances) to eliminate cold-start latency for authenticated users.
- DynamoDB on-demand for AuditTable — bursts with Lambda traffic.

### 9.2 Observability
```
CloudWatch Dashboards:
 - Auth metrics: login success/failure rate, registrations/hour
 - Lambda Duration p50/p95/p99 per function
 - SQS queue depth & DLQ message count
 - API Gateway 4xx / 5xx error rates

CloudWatch Alarms:
 - Login failure rate > 5% over 5 min → SNS alert (potential attack)
 - DLQ messages > 0 → SNS alert
 - Lambda error rate > 1% over 5 min → SNS alert
 - Auth Lambda p95 > 3s → SNS alert

X-Ray Service Map:
 - API Gateway → Cognito Authorizer → Lambda → DynamoDB
 - auth_handler → Cognito User Pool

CloudTrail:
 - All Cognito admin API calls logged for security audit
```

```python
# lambdas/auth_handler/tests/test_unit.py
import json
import pytest
from unittest.mock import patch, MagicMock
from auth_handler.handler import lambda_handler

def make_event(path, body):
 return {
 "rawPath": path,
 "requestContext": {"http": {"method": "POST", "sourceIp": "1.2.3.4"}},
 "headers": {"user-agent": "pytest"},
 "body": json.dumps(body)
 }

@patch("auth_handler.cognito_client.CognitoAuthClient.login")
@patch("auth_handler.handler.write_audit")
def test_login_success(mock_audit, mock_login):
 mock_login.return_value = {
 "AccessToken": "tok123",
 "RefreshToken": "ref456",
 "ExpiresIn": 3600
 }
 event = make_event("/auth/login", {"email": "user@test.com", "password": "Pass1234"})
 response = lambda_handler(event, {})
 assert response["statusCode"] == 200
 body = json.loads(response["body"])
 assert body["access_token"] == "tok123"
 assert body["token_type"] == "Bearer"
 mock_audit.assert_called_once()

@patch("auth_handler.cognito_client.CognitoAuthClient.login")
def test_login_invalid_credentials(mock_login):
 from botocore.exceptions import ClientError
 mock_login.side_effect = ClientError(
 {"Error": {"Code": "NotAuthorizedException", "Message": "Incorrect"}},
 "InitiateAuth"
 )
 event = make_event("/auth/login", {"email": "user@test.com", "password": "wrong"})
 response = lambda_handler(event, {})
 assert response["statusCode"] == 401

def test_login_missing_fields():
 event = make_event("/auth/login", {"email": "user@test.com"}) # missing password
 response = lambda_handler(event, {})
 assert response["statusCode"] == 400

@patch("auth_handler.cognito_client.CognitoAuthClient.register")
@patch("auth_handler.handler.write_audit")
def test_register_success(mock_audit, mock_register):
 mock_register.return_value = {"UserSub": "abc-123"}
 event = make_event("/auth/register", {"email": "new@test.com", "password": "Pass1234"})
 response = lambda_handler(event, {})
 assert response["statusCode"] == 201
```
