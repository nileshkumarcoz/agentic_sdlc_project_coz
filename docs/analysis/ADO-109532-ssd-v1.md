## 3. Data Model

### 3.1 `LogEvent` (dataclass)

```python
@dataclass
class LogEvent:
 event_id: str # uuid4
 detected_at: datetime # UTC
 source: str # file path or stream name
 line_number: int # 0 if stream
 raw_line: str # original log text
 matched_rule_id: str # rule that triggered
 severity: str # DEBUG|INFO|WARNING|ERROR|CRITICAL
 snippet: str # matched substring
 extra: dict # arbitrary rule-defined metadata
```

### 3.2 `WatchRule` (dataclass)

```python
@dataclass
class WatchRule:
 rule_id: str
 pattern: re.Pattern # compiled regex
 severity: str
 multiline: bool
 multiline_terminator: Optional[re.Pattern]
 description: str
```

### 3.3 Config Schema (YAML)

```yaml
# configs/log_watcher_config.yaml
sources:
 - type: file
 path: /var/log/agentic_pipeline.log
 from_beginning: false

rules:
 - rule_id: agent_error
 pattern: "ERROR.*agent"
 severity: ERROR
 multiline: false
 description: "Any error emitted by an agent"

 - rule_id: stack_trace
 pattern: "Traceback \\(most recent call last\\)"
 severity: CRITICAL
 multiline: true
 multiline_terminator: "^(?!\\s)"
 description: "Python stack trace start"

handlers:
 - type: console
 - type: webhook
 url: "${LOG_WATCHER_WEBHOOK_URL}"

metrics:
 enabled: true
 interval_seconds: 60
```

## 4. Key APIs / Interfaces

### 4.1 `LogWatcher` (public orchestrator)

```python
class LogWatcher:
 def __init__(self, config: WatcherConfig): ...

 def add_handler(self, handler: BaseHandler) -> None: ...

 def start(self) -> None:
 """Starts reader thread(s) and dispatcher thread."""

 def stop(self, timeout: float = 5.0) -> None:
 """Signals threads to stop and waits for clean shutdown."""

 def __enter__(self) -> "LogWatcher": ...
 def __exit__(self, *args) -> None: ...

 @property
 def metrics(self) -> MetricsSnapshot: ...
```

### 4.2 `LogSourceReader` (internal)

```python
class LogSourceReader:
 def __init__(self, source_config: SourceConfig, line_callback: Callable[[str, int], None]): ...
 def run(self) -> None: # blocking; run in thread
 """Opens source, tails/reads, calls line_callback per line."""
 def stop(self) -> None: ...
```

### 4.3 `PatternEngine`

```python
class PatternEngine:
 def __init__(self, rules: List[WatchRule]): ...

 def match(self, line: str) -> Optional[WatchRule]:
 """Returns first matching rule or None."""

 def flush_multiline_buffer(self) -> Optional[Tuple[WatchRule, str]]:
 """Returns assembled multiline block if terminator seen."""
```

### 4.4 Handler Interface

```python
class BaseHandler(ABC):
 @abstractmethod
 def handle(self, event: LogEvent) -> None: ...

class ConsoleHandler(BaseHandler): ...
class CallbackHandler(BaseHandler):
 def __init__(self, fn: Callable[[LogEvent], None]): ...
class WebhookHandler(BaseHandler):
 def __init__(self, url: str, timeout: float = 3.0): ...
```

## 6. Technology Choices

| Concern | Choice | Rationale |
|---|---|---|
| Language | Python 3.9+ | Matches existing repo stack |
| Concurrency | `threading` (Reader thread per source + 1 Dispatcher thread) | Simple, avoids asyncio complexity; log I/O is not CPU-bound |
| Queue | `queue.Queue` (bounded, maxsize=10,000) | Thread-safe, back-pressure via `block=False` + drop metric |
| Config parsing | `PyYAML` + `pydantic` v2 for validation | Type-safe config; already common in agentic SDLC projects |
| Pattern matching | `re` (stdlib) with compiled patterns | Zero dependency, fast |
| Testing | `pytest`, `pytest-timeout`, `unittest.mock` | Consistent with Python ecosystem |
| HTTP webhooks | `requests` (sync, in dispatcher thread) | Simple; async not needed at this scale |
| File tail | Custom inode-aware tail (pure Python) | Avoids `sh`/`subprocess`; portable |

## 7. Non-Functional Design

### 7.1 Security
- Config file values support `${ENV_VAR}` expansion; no secrets hard-coded.
- Webhook handler uses HTTPS only (enforced by URL validation in `WebhookHandler.__init__`).
- Log lines are treated as untrusted strings; regex matching only, no `eval`.
- PII masking hook: `PatternEngine` can apply a pre-match sanitiser callable (future extension point defined but not implemented in v1).

### 7.2 Scalability
- One `LogSourceReader` thread per source; thread pool can be bounded via config (`max_sources`).
- `EventQueue` is bounded (configurable `maxsize`); overflow drops oldest event and increments `metrics.dropped_events`.
- Handlers are called sequentially in dispatcher thread; slow handlers (e.g., webhook) should be wrapped with a timeout to prevent head-of-line blocking.

### 7.3 Reliability
- `LogSourceReader` catches `UnicodeDecodeError`, `OSError`; logs internally and continues.
- File rotation detection: reader tracks inode on POSIX; on inode change, closes and reopens file.
- Dispatcher thread is a daemon thread; `stop()` sets a `threading.Event` and joins with timeout to ensure clean exit.

### 7.4 Observability (Internal Metrics)

```python
@dataclass
class MetricsSnapshot:
 lines_read: int
 lines_matched: int
 events_emitted: int
 events_dropped: int
 handler_errors: int
 uptime_seconds: float
 rules_hit: Dict[str, int] # rule_id -> count
```
- Metrics exposed via `watcher.metrics` property (poll-able).
- Optional periodic logging of metrics to stdout at configurable interval.

## 8. Test Strategy

### 8.1 Unit Tests

| Test File | Coverage Target |
|---|---|
| `test_pattern_engine.py` | Single-line match, no-match, multiline assembly, case sensitivity, invalid regex graceful handling |
| `test_reader.py` | File reading with mock `open`, inode-change simulation, encoding error handling, stop signal |
| `test_handlers.py` | ConsoleHandler output capture, CallbackHandler invocation count, WebhookHandler HTTP mock (responses library) |
| `test_config.py` | Valid YAML load, missing required field validation error, env-var expansion |
| `test_watcher.py` | Lifecycle (start/stop), context manager, `add_handler` before and after start, metrics increment |

### 8.2 Integration Tests

**`test_watcher_integration.py`**
- Spin up a `LogWatcher` against a temp log file.
- Write lines via a helper thread (simulating a pipeline agent).
- Assert that `CallbackHandler` receives expected `LogEvent` objects within 500 ms (enforced by `pytest-timeout`).
- Test rotation: truncate / replace log file mid-run and confirm watcher recovers.
- Test high-volume: write 50,000 lines rapidly; assert `metrics.dropped_events` is within acceptable threshold.

### 8.3 Fixture Strategy
- `fixtures/sample_logs/` contain static `.log` files for deterministic unit tests.
- `conftest.py` provides `tmp_log_file` and `watcher_with_callback` pytest fixtures for reuse.
- `pytest-timeout` (global 10 s timeout per test) prevents hung tail operations in CI.

### 8.4 CI Integration
- Add `pytest tests/` step to existing GitHub Actions workflow in `agentic_sdlc_project_coz`.
- Coverage threshold: ≥ 85% line coverage enforced via `pytest-cov --fail-under=85`.
